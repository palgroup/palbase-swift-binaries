# Palbase for iOS — binaries

The XCFramework zips that [palgroup/palbase-swift](https://github.com/palgroup/palbase-swift)'s `Package.swift` names, served by GitHub Pages: `https://palgroup.github.io/palbase-swift-binaries/<version>/<Product>.xcframework.zip`.
